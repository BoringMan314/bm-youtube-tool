隱私權政策

擴充功能名稱：[B.M] YouTube 工具箱（以下稱「本擴充功能」）。

本政策說明本擴充功能如何處理與您相關的資訊。使用本擴充功能即表示您同意本政策內容。

一、資料收集

本擴充功能不會向開發者伺服器蒐集、儲存或上傳任何可識別個人身分的資料，亦不會將您的瀏覽或觀看紀錄傳送至第三方分析或廣告服務。

本擴充功能未使用遠端可執行程式、分析（Analytics）或廣告追蹤；所有程式皆隨擴充功能套件封裝。

二、運作方式與權限範圍

本擴充功能在您主動於工具列開啟並操作時，於 https://www.youtube.com 目前分頁注入腳本，以該分頁既有的登入狀態向 YouTube 同站 API 發送讀取與播放清單編輯請求（排序、複製、匯入等）。相關進度可保存在瀏覽器本機的 chrome.storage.local；您可選擇手動匯出掃描快取 JSON（不含登入 Cookie 或授權權杖）。

三、第三方服務

您使用 YouTube 本身時，該網站可能依其自有隱私權政策處理資料；該部分與本擴充功能無涉，請參閱 Google／YouTube 之說明。

四、政策變更

若本擴充功能之資料處理方式有重大變更，將於本頁面更新；建議您不定期查閱本政策。

五、聯絡方式

若您對本政策有疑問，請透過 Chrome 線上應用程式商店上本擴充功能頁面所提供之開發者聯絡方式，或專案 GitHub Issues 與我聯繫。
